\vspace{3pt}
{\large\bfseries\color{memoBlue}What the result does---and does not---show}

\begin{itemize}
  \item \textbf{Connected equal-time moments carry useful dynamical
  information.}  At $(0.5,0.5,1)$, the raw-closure/coherent error ratios are
  $0.247$ for the electronic 1-RDM, $0.168$ for polarization, and $0.390$ for
  the coherent phonon amplitude.
  \item \textbf{Representability and observable accuracy separate.}  All 12
  raw trajectories violate the joint-Gram condition, yet five never cross the
  exploratory $0.1$ instantaneous 1-RDM-error threshold by $t=4$.  The pooled
  rank association between violation severity and 1-RDM error is $+0.59$, but
  becomes $-0.49$ and $-0.89$ after stratifying the six cases at each coupling.
  The present grid therefore supports an early-warning interpretation, not a
  calibrated error predictor.
  \item \textbf{A physicality barrier is not an accuracy correction.}  It keeps
  the necessary Gram condition nonnegative but beats coherent-only 1-RDM error
  in only 7 of 12 cases, compared with 10 of 12 for the unmodified closure.
\end{itemize}

\noindent\colorbox{memoWarm}{%
  \parbox{0.972\linewidth}{%
  \textbf{Concrete discussion question.}  Does this separation between
  useful non-Markovian observable corrections and loss of necessary
  representability also occur in the authors' spin-reduced implementation?
  If so, which omitted equal-time moments or algebraic constraints should be
  retained to preserve the source-point accuracy gain without violating the
  enforced necessary physicality conditions?  A spin-reduced supplement or
  one reference trajectory would enable a true parity test.}}
